# SEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Improve local search visibility for "IT support Los Angeles" by adding technical SEO foundations and on-page signals.

**Architecture:** Six independent file changes — sitemap integration, robots.txt, doom noindex, global_settings content updates, manifest.json branding fix, and Layout.astro head tag additions (JSON-LD, canonical, Twitter/X card). No changes to visible page copy.

**Tech Stack:** Astro 5, `@astrojs/sitemap`, pnpm, Cloudflare Pages

### Task 1: Install sitemap integration and configure astro.config.mjs

**Files:**
- Modify: `astro.config.mjs`

- [ ] **Step 1: Install `@astrojs/sitemap`**

```bash
pnpm add @astrojs/sitemap
```

Expected output: package added to `dependencies` in `package.json`.

- [ ] **Step 2: Update `astro.config.mjs`**

Replace the entire file with:

```js
import { defineConfig } from 'astro/config'
import tailwindcss from '@tailwindcss/vite'
import sitemap from '@astrojs/sitemap'

export default defineConfig({
  site: 'https://chriscastrotech.com',
  integrations: [
    sitemap({
      filter: (page) => !page.includes('/doom')
    })
  ],
  vite: {
    plugins: [tailwindcss()]
  },
  experimental: {
    fonts: [{
      provider: "local",
      name: "InterLocal",
      cssVariable: "--font-inter",
      variants: [
        { weight: 400, style: "normal", src: ["./src/assets/fonts/Inter-Regular.woff2"] },
        { weight: 600, style: "normal", src: ["./src/assets/fonts/Inter-SemiBold.woff2"] },
        { weight: 700, style: "normal", src: ["./src/assets/fonts/Inter-Bold.woff2"] }
      ]
    },
    {
      provider: "local",
      name: "InterLocalDisplay",
      cssVariable: "--font-inter-display",
      variants: [
        { weight: 400, style: "normal", src: ["./src/assets/fonts/InterDisplay-Regular.woff2"] },
        { weight: 500, style: "normal", src: ["./src/assets/fonts/InterDisplay-Medium.woff2"] },
        { weight: 600, style: "normal", src: ["./src/assets/fonts/InterDisplay-SemiBold.woff2"] }
      ]
    }]
  }
})
```

- [ ] **Step 3: Build and verify sitemap is generated**

```bash
pnpm run build
```

Check that these files exist:
```bash
ls dist/sitemap-index.xml dist/sitemap-0.xml
```

Also confirm `/doom` is excluded:
```bash
grep -v doom dist/sitemap-0.xml && echo "doom excluded OK"
```

- [ ] **Step 4: Commit**

```bash
git add astro.config.mjs package.json pnpm-lock.yaml
git commit -m "feat(seo): add @astrojs/sitemap integration, exclude /doom"
```

### Task 6: Add JSON-LD schema, canonical URL, and Twitter/X card to Layout.astro

```astro

    <meta name="twitter:title" content={ title ?? global_settings.title } />
    <meta name="twitter:description" content={ description ?? global_settings.description } />

    <!-- LocalBusiness structured data -->
    <script type="application/ld+json">
    {
      "@context": "https://schema.org",
      "@type": "ProfessionalService",
      "name": "Chris Castro Technical Solutions",
      "url": "https://chriscastrotech.com",

      "email": "chris@chriscastrotech.com",
      "description": "Expert IT support and consulting in Los Angeles, CA. Hard drive recovery, computer repair, network setup, and emergency support.",
      "priceRange": "$$",
      "areaServed": {
        "@type": "City",
        "name": "Los Angeles",
```
